# 天空关键帧资源

`sky_0000.png`、`sky_0500.png`、`sky_0600.png`、`sky_0800.png`、`sky_1200.png`、`sky_1700.png`、`sky_1900.png` 和 `sky_2100.png` 是 1774×887 的真实感 2:1 经纬度栅格贴图。它们描述同一套天气系统随时间平移、生长、分裂和消散后的不同状态，而不是重复使用完全一致的云形。

Shader 使用经纬度 UV，并在左右边缘各 1% 的窄区域内融合接缝，避免生成式全景图在球面背后出现竖线。太阳与月亮不烘焙进贴图，由 Shader 独立绘制和移动。

运行时仅持有当前与下一张贴图，并预取再下一张。每帧的 `cloud_phase` 表示天气系统已经绕天空前进的经度相位；可见天空和环境天空 Shader 在交叉淡化前将两张贴图运动补偿到当前相位，减少双重云团和位置跳变。环境天空同时向模型提供漫反射辐照和 PBR 反射。跨午夜相位按连续值展开，因此全天循环不会倒退。

替换正式美术资源时，应继续使用 2:1 经纬度 PNG，并尽量保持左右边缘一致。相邻关键帧应保留可辨识的天气连续性，同时实际改变云体轮廓与局部结构。`sky_timeline.json` 保存贴图路径、云层相位、环境光、太阳颜色和能量；时间轴允许不等间距关键帧，控制器会校验坏帧和重复时间。

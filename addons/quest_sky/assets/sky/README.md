# 天空关键帧资源

`sky_00.svg` 至 `sky_23.svg` 分别对应全天每个整点。当前资源是 1024×1024 的风格化经纬度贴图，由倒置 `SphereMesh` 的原生 UV 在当前与下一关键帧之间插值。

原始版本错误地用八面体 UV 采样这些普通纵向渐变和横向云带，导致地平线颜色随方位角变化。当前运行时不再执行八面体映射，贴图中的纵向渐变、云带和星点会按球面经纬度稳定显示。

运行时仅持有当前与下一张贴图，并预取再下一张。太阳与月亮不要烘焙进贴图，它们由 Shader 独立绘制和移动。

替换正式美术资源时，建议使用 2:1 经纬度贴图并保持左右边缘无缝。`sky_timeline.json` 保存贴图路径、环境光、太阳颜色和能量；时间轴允许不等间距关键帧，控制器会校验坏帧和重复时间。
